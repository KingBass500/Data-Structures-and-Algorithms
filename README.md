# Data Structures and Algorithms in Python

A beginner-friendly Python project demonstrating common data structures and algorithms.

## Included topics

### Data structures
- Arrays (Python lists)
- Stacks
- Queues
- Singly linked lists

### Algorithms
- Linear search
- Binary search (requires sorted input)
- Bubble sort

## Requirements
- Python 3.10 or newer recommended
- Visual Studio Code (VS Code)

No third-party Python packages are required.

## Run in VS Code
1. Open VS Code.
2. Select **File → Open Folder** and choose `data-structures-algorithms`.
3. Open `main.py`.
4. Open **Terminal → New Terminal**.
5. Run one of these commands:

   ```bash
   python main.py
   ```

   If `python` is not recognized on Windows, try:

   ```powershell
   py main.py
   ```

## What the program demonstrates
- An array/list can store multiple values.
- A stack removes the most recently added item first (LIFO).
- A queue serves the earliest added item first (FIFO).
- A linked list connects nodes together.
- Linear search checks each value in order.
- Binary search repeatedly halves a sorted search range.
- Bubble sort swaps neighbouring values into ascending order.
